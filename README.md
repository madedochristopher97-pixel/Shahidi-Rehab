# Shahidi Centre for Recovery 🌿

> **"Witnessing Recovery, Transforming Lives."**

A compassionate, physician-led addiction rehabilitation and mental health recovery centre website providing evidence-based medical detox, residential care, and lifelong family support in a calm natural sanctuary in Nairobi, Kenya.

---

## ✨ Features & Architecture

- **Pure Imagery & Dynamic Full-Bleed Hero**: Unboxed, immersive visual presentation featuring natural photography and delicate directional contrast grading.
- **Adaptive Transparent Navigation Bar**: Seamlessly transitions from colorless at the top to a frosted-glass contrasting header upon scrolling (`scrollY > 20px`).
- **Complete Page Suite**:
  - `index.html`: Homepage with interactive pathway navigation, clinical credentials strip, facility tour, and programs overview.
  - `about.html`: Clinical leadership, treatment philosophy, and multidisciplinary medical team.
  - `programs.html`: Levels of care (Medical Detox, Residential Inpatient, Intensive Outpatient, Family Therapy & Aftercare) with interactive FAQ accordion.
  - `admissions.html`: Step-by-step admissions guide, financial transparency, and interactive confidential assessment intake form with real-time feedback.
  - `resources.html`: Psychoeducation library, family support guides, crisis helplines, and recovery community stories.
  - `contact.html`: Confidential inquiry form, direct 24/7 hotline links, WhatsApp instant consultation integration, interactive FAQ, and visiting hours.
  - `privacy.html` & `terms.html`: Patient rights, confidentiality, and legal compliance.
- **Universal Quick-Help Modal**: One-click confidential assistance accessible from any page header or call-to-action button.
- **Strict Brand Design System**:
  - Primary Shahidi Blue: `#024F83`
  - Growth Shahidi Green: `#579059`
  - Warm Off-White / Cream: `#FAF8F5`
  - Local typography loading: Cooper BT Regular for headlines & Elms Sans for body text.
  - Accessible 8px grid system throughout.
  - Full WCAG AA accessibility compliance with `prefers-reduced-motion` support.

## 🚀 Getting Started

No build tools or heavy node dependencies required—pure modern HTML5, CSS3, and vanilla JavaScript.

### Running Locally

You can serve the directory using any static file server:

```bash
# Python 3
python -m http.server 8080
```

Then navigate to:
```
http://localhost:8080/index.html
```
